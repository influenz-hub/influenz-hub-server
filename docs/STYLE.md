```markdown
# Influenz Hub — STYLE.md

## 1. Brand Identity

### Name

**Influenz Hub**

### Vision

Influenz Hub is a platform designed to discover, showcase, and empower independent creators, brands, and talents.

It is not only a marketplace.

It is a digital space where ideas become visible, creators grow, and communities connect.

### Brand Statement

> "Where independent ideas become influential."

---

# 2. Design Philosophy

Influenz Hub should feel:

* Creative
* Ambitious
* Premium
* Connected
* Futuristic
* Human

The experience should communicate:

"Someone is building something here."

Avoid:

* Cheap marketplace feeling
* Overcrowded layouts
* Corporate coldness
* Generic e-commerce visuals

---

# 3. Visual Identity

## Main Theme

### Concept:

**Digital Purple Ecosystem**

Purple represents:

* Creativity
* Influence
* Transformation
* Innovation
* Growth

The interface should feel like a world where creators shine.

---

# 4. Color System

## Primary Colors

### Influenz Purple

```
#7C3AED
```

Used for:

* Main buttons
* Highlights
* Brand elements
* Active states

### Electric Violet

```
#A855F7
```

Used for:

* Gradients
* Glow effects
* Premium sections

### Deep Space

```
#09090B
```

Used for:

* Dark backgrounds
* Main website sections
* App theme

### Soft Lavender

```
#E9D5FF
```

Used for:

* Secondary highlights
* Background accents

---

# 5. Typography

## Style

Modern + confident.

Recommended fonts:

### Headings:

* Inter
* Satoshi
* Plus Jakarta Sans

### Body:

* Inter
* Manrope

---

## Typography Rules

Large titles:

Example:

"Discover people creating the future."

Should feel bold and inspiring.

Avoid small, compressed text.

---

# 6. UI Style

## Shape Language

Everything should feel approachable.

Use:

* Rounded corners
* Smooth cards
* Soft shadows
* Spacious layouts

Recommended radius:

```
Small:
12px

Cards:
20px

Large sections:
32px
```

---

# 7. Glass & Glow Style

Influenz Hub can use a futuristic glass style.

Examples:

Cards:

* Slight transparency
* Blur background
* Purple glow

Concept:

```
Dark background

      ✨
  Creator Card

Purple light behind it
```

---

# 8. Components

## Buttons

Primary:

```
[ Discover Indies ]
```

Style:

* Purple background
* White text
* Rounded
* Soft glow on hover

Secondary:

```

```
Style:

* Transparent
* Purple border
```

```
# 12. Homepage Style

## Hero Section

Large statement:

"Discover the minds behind the next big things."

Background:

* Purple gradient
* Floating cards
* Animated particles

Actions:

```
Explore

```

---

# 13. Animations

Animations should feel alive.

Use:

* Fade transitions
* Smooth scrolling
* Card movement
* Hover effects
* Small celebrations

Avoid:

* Fast aggressive animations
* Too many effects

---

# 14. Icons

Style:

* Rounded
* Minimal
* Modern

Recommended:

* Lucide Icons
* Phosphor Icons

```

Profile
```

# 16. Indie Growth System

Influenz should show progression.

Levels:

```
🌱 Emerging

🔥 Growing

💎 Influential

👑 Featured
```

The system represents creator growth.

---

# 17. Website Style

The website should feel like a movement.

Structure:

```

Discover Indies

How Influenz Helps

Featured Creators

Success Stories

Join Influenz
```

---

# 18. Photography Style

Images should show:

* Real people
* Real products
* Real creations

Avoid:

* Generic stock photos
* Artificial corporate imagery

---

# 19. Brand Personality

Influenz speaks like:

Confident:

"We help creators get seen."

Not:

"We provide a platform solution."

Human:

"Discover someone building something amazing."

Not:

"Browse available commercial entities."

---

# 20. Final Feeling

When someone opens Influenz Hub, they should think:

"I found a place where creators matter."

The app is not a catalog.

It is a spotlight.
```
